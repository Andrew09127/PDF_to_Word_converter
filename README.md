# Конвертер отсканированных PDF → DOCX (юридические заявления)

Превращает отсканированные/нативные PDF (заявления о включении в РТК и т.п.) в
редактируемые DOCX, максимально близкие по вёрстке к оригиналу. **Работает
полностью локально** — никакие данные не уходят в интернет.

## Состав
- **Docling** — анализ макета страниц + OCR (EasyOCR, `ru+en`).
- **python-docx** — генерация DOCX (таблицы метка|значение, шапка, штамп ЭП).
- `docling_dev/` — логика: порядок чтения, OCR-фиксы, вёрстка, подсветка.
- Исполняемых файлов в репозитории нет — только Python-исходники.

## Установка (другой разработчик)
```bash
git clone <репозиторий>
cd Convert
python -m venv .venv
.venv\Scripts\activate            # Windows  (Linux/Mac: source .venv/bin/activate)
pip install -r requirements.txt   # OCR-доп.: pip install -r requirements-ocr.txt
```
Требуется Python 3.12. Модели OCR (EasyOCR/Docling) скачиваются автоматически при
первом запуске и далее работают офлайн.

## Запуск
```bash
# батч из папки pdf_to_convert/ → converted_word_docling/
python convert_docling_dev.py

# один файл
python convert_docling_dev.py "путь/к/файлу.pdf" --output out_dir
```
Полезные флаги:
- `--word-order` — включить EasyOCR-переупорядочивание блоков (по умолчанию ВЫКЛ:
  нативный порядок Docling точнее и не ломает вёрстку).
- `--no-highlight` — не подсвечивать жёлтым подозрительные (искажённые OCR) слова.
- `--llm` — локальная LLM-доочистка остатка (см. ниже).

## Очистка OCR-ошибок
1. **Детерминированная** (всегда вкл): нормализация помеченных слов — гомоглифы
   латиница→кириллица (`co→со`), случайные заглавные (`должНЫ→должны`).
2. **Подсветка**: что не починилось автоматически — выделяется жёлтым для
   быстрой ручной вычитки.
3. **LLM-доочистка (опционально, `--llm`)**: добивает оставшиеся подсвеченные
   слова. Работает только по ним (не по всему документу) → быстро даже на CPU.

### Опциональная локальная LLM (Ollama)
Полностью локально (инференс на CPU, `localhost`, наружу ничего не уходит).
Разовая установка:
```bash
winget install Ollama.Ollama        # или установщик с ollama.com
ollama pull qwen2.5:3b              # ~2 ГБ, разово (можно скопировать офлайн)
```
Затем:
```bash
python convert_docling_dev.py --llm                 # модель по умолчанию qwen2.5:3b
python convert_docling_dev.py --llm --llm-model qwen2.5:1.5b
```
Если Ollama не установлена/не запущена — шаг просто пропускается (программа
работает как обычно). Правки LLM проходят жёсткие предохранители: не меняются
цифры/номера/ФИО, правка должна быть мелкой (иначе отклоняется как галлюцинация).

## Тесты вёрстки (golden)
```bash
python tests/golden.py save     # снять эталоны из converted_word_docling/
python tests/golden.py check    # сверить текущий вывод с эталонами (diff)
```
Ловит регрессии состава/порядка текста при изменениях кода.
